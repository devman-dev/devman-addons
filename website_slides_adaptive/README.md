# Website Slides Adaptive

Este módulo agrega capacidades de aprendizaje adaptativo a Odoo eLearning:
- Seguimiento de progreso por usuario y slide
- Rutas de aprendizaje personalizadas
- Motor de recomendaciones
- Dashboards para estudiantes y profesores

## Instalación
1. Copiar a tu carpeta de addons
2. Actualizar lista de módulos
3. Instalar

## Uso
Accede al dashboard desde `/slides/adaptive/dashboard`
