The Approval Module of Odoo Community Version

Approval module allows you manage all requests, review, then approve them.

User Interface

Menu Function
Approvals > Dashboard The main dashboard which can be viewed in a number of different ways
Approvals > Approvals > To Review This menu lists all requests need to be reviewed by you
Approvals > Approvals > My Requests Show the requests made by you

User Groups

  • Settings: can create / edit the approval type
  • User: can create / approve the approval request

On the form view of user, choose "User" or "Settings"

Access Rules

We create 4 record rules to make sure: An employee can only see their requests. A manager can review and approve for the employee of his department. An Admin can see all

Configuration

Create all request types needed for your company's policy. The dashboard shows all types with their summary information
